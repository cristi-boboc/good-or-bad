# Good or Bad? 

A fast-paced multiplayer party game of quick reflexes and sharp eyes!

## [Play Now](https://cristi-boboc.github.io/good-or-bad/)

## How to Play

1. **Host** creates a game and gets a 5-digit PIN
2. **Players** join using the PIN and set their names
3. Everyone sits around a virtual table
4. A mysterious covered item appears in the center
5. The cover lifts — is it **good** or **bad**?
6. The items look almost identical — spot the tiny difference!
7. **GRAB** it fast if it's good (+1 point), but beware — grabbing a bad item costs you (-1 point)
8. First player to reach **6 points** wins!

## Features

- Real-time multiplayer via peer-to-peer connections (no server needed)
- 5-digit PIN to join games easily
- 8 different item types with very subtle good/bad differences
- Synthesized sound effects and background music
- Works on desktop and mobile browsers
- Up to 8 players per game

## Item Differences

Each item type has a nearly identical good and bad version. Study them carefully in the lobby guide before the game starts! The differences include things like slightly off colors, tiny visual details, or subtle shape changes.

## Tech Stack

- Vanilla HTML/CSS/JavaScript
- PeerJS for WebRTC peer-to-peer networking
- Web Audio API for synthesized sounds and music
- Hosted on GitHub Pages
